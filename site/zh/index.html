安装与连接

连接你的 Mac。

MCP 服务器让代理访问本地终端。先准备 iTerm2，再配置使用它的 MCP 客户端。

查看完整文档 ↗

  1. 准备 iTerm2

    使用 macOS，并保持 iTerm2 运行。在 Settings → General → Magic 中启用 Python API，首次连接时批准 iTerm2 授权提示。

  2. 检查安装包

    如未安装 uv，请按其官方说明安装。当前文档使用 0.2.1 版本和 Python 3.12。

    uvx --python 3.12 goals-iterm-mcp@0.2.1 --help

    安装 uv · PyPI 0.2.1

  3. 配置 MCP 客户端

    执行 command -v uvx 获取绝对路径。按客户端支持的格式添加下面的配置，并保留其他已有设置。

    {
  "mcpServers": {
    "iterm": {
      "command": "/absolute/path/to/uvx",
      "args": [
        "--python",
        "3.12",
        "goals-iterm-mcp@0.2.1",
        "serve"
      ]
    }
  }
}
  4. 验证连接

    重新加载 MCP 连接，检查工具发现，并调用 list_sessions。执行任务前，先在 iTerm2 中完成目标 Coding CLI 的登录配置。

客户端必须能够访问这台 Mac。纯云端聊天无法直接连接本地 iTerm2；手机使用需要远程界面连接到具备本地 MCP 访问能力的代理。

它和配套 Skill 有什么区别？

MCP 服务器提供终端操作工具。goals-iterm-skill 提供任务委托、监控、决策、恢复和验收的流程指令。

服务器可以访问哪些终端？

默认可以操作当前用户的所有 iTerm2 会话。使用 --read-only 仅观察；使用一个或多个 --session-id <ID> 限定会话。限定会话后无法创建窗口和标签页。

发送成功是否代表命令完成？

不代表。确认信息只说明 iTerm2 API 调用成功，协调代理仍需查看终端输出并验证执行结果。

它自带后台监控服务吗？

不自带。服务器提供终端工具；监控、持续推进和调度由协调代理及其宿主负责。
